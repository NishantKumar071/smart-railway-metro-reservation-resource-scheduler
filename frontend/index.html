⚙️ OS Concepts — Live Implementation

Not theoretical — these concepts run every time a booking is made

🔀

Multithreading

6 worker threads process booking requests concurrently using Python's threading module

📥

Producer-Consumer

HTTP handlers produce; worker threads consume from a bounded priority queue with Condition variables

⚡

Priority Scheduling

EMERGENCY → SENIOR → TATKAL → NORMAL with deterministic tie-breaking via heapq

🔒

Mutex & Sync

threading.Lock, threading.Condition, threading.Event for race condition prevention

🛡️

Deadlock Prevention

Single-lock protocol: only one lock ever acquired at a time in the scheduler

📊

Live Telemetry

Real-time worker thread metrics, queue depth, processing times — all from live system state
